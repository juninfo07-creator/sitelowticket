# Landing Page Low Ticket — Venda Todo Dia Sem Virar Refém do iFood

Landing page de alta conversão para o guia digital de **Daniel Junior**, desenvolvido para confeiteiras e produtoras caseiras que desejam criar uma estrutura própria de vendas no WhatsApp e reduzir a dependência de marketplaces como o iFood.

## Estrutura da Página
- **Seção 01 (Hero):** Headline de alto impacto, subheadline clara, CTA principal e fotografia de suporte visual.
- **Seção 02 (O Problema):** Card financeiro comparativo demonstrando o impacto real das taxas do marketplace sobre a margem de lucro.
- **Seção 03 (A Solução):** Fluxo prático de 5 etapas (Instagram → Anúncio local → WhatsApp → Venda direta → Recompra).
- **Seção 04 (Por Dentro do Guia):** Detalhamento dos 5 módulos práticos + plano de ação de 30 dias com mockup 3D integrado.
- **Seção 05 (Ferramentas & Bônus):** Os 4 bônus práticos incluídos para acelerar a execução (Checklist, Templates de Stories, Scripts de WhatsApp e Calculadora de Lucro).

## Tecnologias
- HTML5 Semântico
- CSS3 Moderno (Custom Properties, Grid & Flexbox, Mobile-First)
- JavaScript Vanilla (Microinterações)
